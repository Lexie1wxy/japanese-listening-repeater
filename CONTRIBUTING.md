# Contributing

Thanks for helping improve Japanese Listening Repeater.

## Good First Contributions

- Improve mobile layout.
- Add subtitle format compatibility.
- Improve keyboard controls.
- Add import/export for playlists.
- Improve accessibility and screen reader labels.
- Add translations for the interface.

## Copyright

Do not include copyrighted audio, full transcripts, commercial subtitles, or other third-party learning materials in issues, pull requests, fixtures, screenshots, or examples unless you have explicit permission to publish them.

Use short original examples when demonstrating behavior.

## Development

This project is a static web app. You can run it locally with:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://127.0.0.1:8765/
```
