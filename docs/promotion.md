## 中文发布文案

```text
我开源了一个自用的日语听力复读播放器: japanese-listening-repeater。

它适合做日语精听、shadowing 和听写练习:
- 本地导入自己的音频和字幕
- 点击字幕逐句跳转
- 单句循环
- 段落循环:默认 5 句一段,每段重复 5 遍,再自动进入下一段
- 自动逐句播放
- 音频保存在本机浏览器,不用上传到第三方服务

项目只提供播放器代码,不提供任何受版权保护的音频或字幕。大家可以导入自己有权使用的材料。

GitHub:
https://github.com/Lexie1wxy/japanese-listening-repeater
```

## English Launch Copy

```text
I open-sourced japanese-listening-repeater, a local-first web app for Japanese listening practice.

It is designed for shadowing, dictation, and subtitle-based intensive listening:
- Import your own audio and subtitles locally
- Click any subtitle line to jump to that sentence
- Loop one sentence
- Loop paragraphs: 5 lines by default, 5 repeats, then move to the next block
- Auto sentence-by-sentence playback
- No backend, no upload required

The repository contains only the player code. It does not distribute copyrighted audio, subtitles, or transcripts.

GitHub:
https://github.com/Lexie1wxy/japanese-listening-repeater
```

## Safety Notes

- 不要上传真实广播、影视、教材音频。
- 不要上传完整第三方转写或字幕。
- 截图和演示视频尽量使用自写短句或公开授权素材。
- 发布时强调这是工具,不是素材库。
